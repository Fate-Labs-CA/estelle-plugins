# v0.0.11

Local write protection now recognizes two ordinary source forms that previously looked like
credential assignments: literal-free callback arguments and Python ContextVar reset handles.
The shared implementation is included in the Claude Code, Codex, Kimi, Grok and Cursor packages.

Quoted values, sensitive primitive fields, mixed credential payloads and credential-shaped literals
remain protected. A callback followed by a literal is not waived. Code-looking text inside line or
block comments is not treated as an executable reference. Privacy redaction is unchanged.

The source passed 317 local controls and independent adversarial review, including isolated shipped
CLI calls. The regression controls failed before the fix; review also found and closed two false
allowances before release. These checks do not certify every native host installation.

This release does not change trust settings, native approvals, user configuration, active sessions or
installed caches. It does not fix MCP review availability or the backend's admission capacity.
The explicit setup and migration limits from [v0.0.9](v0.0.9.md) still apply. OAuth setup from the
separate pending 0.0.10 proposal is not included.
