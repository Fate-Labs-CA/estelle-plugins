# v0.0.16

## Cloud and handoff run on the small model in Claude Code

`/estelle:cloud` and `/estelle:handoff` run one command on your machine and show you its link. In Claude Code that step
now runs on Haiku instead of your session's main model, which re-read your whole conversation just to run it.

This changes only that step on your machine. The agent in the cloud box picks its own model on Estelle's side, which is
Sonnet for Claude unless you choose another.

Nothing else changes, and other editors are unchanged.

## Limits

- Not run against a real cloud machine for this release, because each run starts a billed box.
- Whether Claude Code keeps Haiku when the model starts the command itself, rather than you typing it, is unmeasured.
