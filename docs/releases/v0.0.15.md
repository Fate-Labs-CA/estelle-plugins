# v0.0.15

## The write check warns and no longer stops anything

Estelle's hook no longer refuses a file edit, on any host. Your agent can write a key into a file and the edit goes through.

When an edit writes an exact key shape, Estelle names the file and the kind of key, and tells you to rotate it if it's real. It
never repeats the value. The kinds are Stripe, Estelle, GitHub, OpenAI-style and Anthropic keys, Slack tokens, JWTs, private keys
with a body, Postgres URL passwords, and AWS, Google and SendGrid keys.

## What used to stop an edit and now does not

- **Every exact key shape above.** It warns, and the key is in your file.
- **Anything else, with no warning at all:** a value under a name such as `password = "..."` or `session_token = "..."`, an env file
  line, a long opaque value, a password in any URL other than a Postgres one, and a literal bearer header.

## What is unchanged

- Transcripts and session capture are still redacted the same way.
- `/estelle handoff` still leaves flagged files behind rather than pushing them, and still refuses a flagged unpushed commit. That
  scan is separate from this hook.
- Anything server-side that scans pull request content.

## Where you see the warning

| Host | Where |
|---|---|
| Claude Code, Codex | A system message for you, and context for the agent |
| Cursor | A user message and an agent message, with the edit allowed |
| Grok | Context for the agent |
| DeepSeek Harness | The harness log, and a message to the agent |
| Kimi | Hook stderr only: Kimi takes no context at this event, so you may not see it |

Every host also gets the warning on the hook's stderr.

## On Codex, approve the hooks again

This release changes the plugin's files, so Codex asks again: run `/hooks` and press `t`, or choose **Trust all and continue**.

## Limits

- Tested through each host's hook entry point with its own event shape, not inside the real host applications, so whether each
  one displays the words as described above has not been seen on screen.
- An unusual key that matches no listed shape gets no warning.
- A shell command that writes a file is still not looked at.
