# v0.0.18

## Estelle in OpenCode and Pi

Estelle now runs inside two more coding agents:

- **OpenCode** (`@fatelabs/opencode-estelle`, install with `opencode plugin @fatelabs/opencode-estelle -g`): the
  Estelle MCP server, the seven `/estelle:*` commands, the four agents as subagents, the skills and the instructions,
  with session identity, prompt recall, mail at the tool boundary and capture wired to OpenCode's own events.
- **Pi** (`@fatelabs/pi-estelle`, eligible for the pi.dev gallery through the `pi-package` keyword; install with `pi install npm:@fatelabs/pi-estelle`): the Estelle MCP
  server, `/estelle:*` commands, skills, session identity, recall, mail and capture through Pi's extension API.

Both were run live against a real model: the model called Estelle's tools and the hooks ran. See
docs/hosts/opencode.md and docs/hosts/pi.md for exactly what each host supports.

## Limits

- Pi has no sub-agents, so Estelle's four agents are not available there.
- The browser OAuth sign-in path and the billed cloud/handoff commands were not run live in either host.
- Rooms, explicit identity requests and mail sent to OpenCode and Pi sessions need the Estelle server from
  Fate-Labs-CA/estelle#1992.
