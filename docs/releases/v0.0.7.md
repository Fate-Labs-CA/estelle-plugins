# v0.0.7

## Quiet hooks and capture outside Git

Bounded input scans no longer add repeated verification warnings to Claude Code and Codex edits.
These cases retain a partial local status and return the host's normal response. They do not certify
that an edit was checked. Cursor keeps its native response shape.

Session capture can start before a local folder becomes a Git worktree. The starting event omits the
repository when discovery is unavailable; no repository is inferred or backfilled. Recall and reindexing
still require a resolved repository. Existing acknowledgement, replay, account and redaction rules
remain in place.

## Credential-pattern protection

Ordinary source references such as `process.env.API_KEY` no longer count as literal credentials.
Actual sensitive payload values are checked before source normalization. Privacy redaction and its
detection thresholds are unchanged. Pattern matching cannot recognize every possible secret.

Current instructions request source lookups, review and tests. Authorization, funding checks and
actual credential protection remain in place.

## Update an existing installation

Update through the matching [host guide](../install/) and follow the [migration guide](../migration/from-cli.md).
A running host may retain old hooks until its supported reload or a fresh session. This release does
not stop active sessions or replace their loaded configuration. Only remove registrations verified to
belong to the old Estelle CLI; preserve unrelated hooks and the plugin-owned MCP connection.

## Limits

Shared-runtime and adapter tests cover the five generated packages. They do not certify every native
host on every operating system. Grok and Cursor transcript verification limits remain as documented
in [Host support](../SUPPORT.md). Partial capture is not a complete handoff.

Completion metadata alone does not establish edit ownership or link a pull request. Already-consumed
transcripts are not backfilled. This release does not repair the separate hosted Prism execution or
session Git-panel association failures.
