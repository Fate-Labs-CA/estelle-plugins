# v0.0.19

## Commands with nothing after them read as sentences

Hosts put the text after a command in place of `$ARGUMENTS` as written, so a command run with nothing after it left a
hole mid-sentence: `/estelle:resume` alone read "Call estelle_resume for ." and `code`, `monitor`, `review` and
`rooms` had the same gap.

Those five commands now say what to do in plain sentences and end with a labelled line that says what a blank means,
for example "Requested work (blank means the most recent): $ARGUMENTS". The change is in the shared commands and in
every host's generated copy: Claude Code, Codex, Cursor, DeepSeek Harness, Grok Build, Kimi Code, OpenCode and Pi. A
new test runs every shared command with an empty argument and fails on the old wording. (#31)

## Docs

- The OpenCode and Pi install guides, the package READMEs, the README rows and the setup prompts install from npm
  (`opencode plugin @fatelabs/opencode-estelle -g`, `pi install npm:@fatelabs/pi-estelle`). (#30)
- The `estelle` skill's description names OpenCode and Pi among the hosts it is used from. (#30)

## Limits

- Nothing changed in the hooks, the MCP connection or the runtime beyond the version number.
- Pi still has no sub-agents, so Estelle's four agents are not available there.
- Rooms, explicit identity requests and mail sent to OpenCode and Pi sessions depend on the server change in
  Fate-Labs-CA/estelle#1992 (merged 2026-11-19). This release changes nothing on that path and was not re-run
  against it.
